Prompt templates in an MCP server are reusable, predefined prompts that help clients perform common tasks without having to create prompts from scratch. They are defined by the server author and can include parameters that allow the prompt to be customized for different situations.
Clients first discover available prompt templates from the server and then request a specific prompt while providing values for any required parameters. During parameter interpolation, the supplied values are inserted into placeholders within the template to generate the final prompt content.
For example, a template might contain a placeholder such as {topic}. If the client provides "machine learning" as the value, the server generates a prompt tailored to that topic. The prompt function typically returns a structured list of messages that can be sent directly to the AI model. This approach makes prompts reusable, consistent, and easier to maintain across different applications.
