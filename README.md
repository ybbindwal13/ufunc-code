In an MCP system, resources provide read-only data that clients can access without invoking tools. Resources are identified by URIs, which act as unique addresses for the data. A client requests a resource by its URI, and the server returns the associated content, such as text, JSON, or documents.
Resources can be either static or templated. A templated resource uses parameters in the URI, such as docs://documents/{doc_id}. When a client requests docs://documents/123, the MCP Python SDK automatically extracts 123 and passes it as a parameter to the resource function. This makes it easy to access different data items using the same resource definition.
For example, a resource function could return the contents of a document based on the provided document ID. The client simply requests the appropriate URI, and the server returns the corresponding resource data in a structured format.
