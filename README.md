An MCP client communicates with an MCP server by sending function requests defined by the MCP protocol. The client can first discover available tools by requesting a tool list. When a tool is needed, the client sends a tool call with the required parameters, and the server executes the tool and returns the result. For example, a client might request the list of available tools, then call a get_weather tool with a city name and receive the weather information in response. This approach provides a consistent way for applications to access external services and functionality through MCP servers.
