# Command: /monthly-review

Analyze all expenses for the current month and generate:
- Total spending
- Top spending categories
- Budget overruns
- Savings opportunities
- Personalized recommendations

# Command: /expense-forecast

Predict spending for the remainder of the month using:
- Historical spending patterns
- Current spending velocity
- Budget targets

Provide projected end-of-month totals.



# Command: /detect-anomalies

Scan transactions and identify:
- Unusually large expenses
- Duplicate transactions
- Suspicious spending spikes
- Category anomalies

Generate a risk report with explanations.
